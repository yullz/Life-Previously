# Production gates — Rich vs Poor: Dinner Before the French Revolution

All media gates start open. Mark only performed checks, with date, reviewer, method and asset hashes.

- [ ] Director exact-script review and both additional slate review passes complete; package hashes verified
- [ ] Native parser/claims/prompt-plan validation passes; every factual sentence mapped, qualifiers preserved
- [ ] Live model, voice, costs and balance verified; itemized episode allowance authorized
- [ ] Pilot passed at full size; every final submitted payload/reference recorded; no unknown duplicate jobs
- [ ] Every image inspected at native size and against narration; OCR plus human visual text check
- [ ] Returning places and cast compared side by side; historical dates/seasons correct
- [ ] Visitor poses inspected; scale, ground, held props, crop edges, halos and accessory correct
- [ ] Graphics and source notes legible; historical labels correctly dated; no invented artifact facsimiles
- [ ] Each voice chapter actually heard; names, negations, emphasis and joins correct; takes preserved
- [ ] Actual duration10–12min, minimum10, no speed stretching or silent padding
- [ ] Sound cues match visible action and remain below narration; full mix measured near-14LUFS and <=-1dBTP
- [ ] Every composite inspected, captions readable/synchronised; technical export checks pass
- [ ] Entire final video watched and heard continuously in order; samples not counted as playback
- [ ] Three complete thumbnails checked at160/320px and full resolution; lead A selected
- [ ] Three Shorts reviewed for meaning, chronology, portrait composition, captions, sound and actual duration
- [ ] Final package matches chosen master; chapter times derived from actual alignment; title clearance refreshed
- [ ] One clear owner review folder with all deliverables, exact hashes and honest open issues
- [ ] Owner approves publication separately; no automatic upload or scheduling
- [ ] Lessons and measured acceptance/repair costs recorded; no assumed improvement
