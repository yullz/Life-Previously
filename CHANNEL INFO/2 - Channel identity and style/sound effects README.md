# Sound effects

Put sound files here, named exactly as the scripts call them (`[sfx: bell-distant]` plays `bell-distant.wav`, `.mp3`, `.ogg`, `.flac` or `.m4a`). Missing files are skipped with a warning, so you can render before the library is complete.

Use a licensed library cleared for YouTube: Epidemic Sound or Artlist (subscriptions that cover music and effects), or the free YouTube Audio Library. Avoid random downloads, which risk copyright claims. Trim each file so the sound starts immediately.
